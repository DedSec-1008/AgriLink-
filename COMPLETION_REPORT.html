1. Audit Findings Verification & Resolution Status Matrix

# Audit Finding Verified Baseline State Resolution Implemented in Phase P1 Status
1 Repository Lifecycle remember { MockAgriRepository() } inside MainActivity caused full state loss on phone rotation. Implemented AgriAppViewModel scoped to Activity ViewModelStore, preserving lots across recreation. RESOLVED
2 Persistence Clarification Claimed Room usage in UI, but codebase was entirely in-memory without Room DAOs. Clarified architectural status; pruned unused Room compiler dependencies until Phase P2 SQLite implementation. RESOLVED
3 Monolithic SellScreen 5,758-line monolithic composable containing all 11 selling steps in a single file. Modularized into 11 dedicated step composables under com.example.ui.screens.selling. Orchestrator reduced to 163 LOC. RESOLVED
4 Main-Thread Geocoder geocoder.getFromLocation() ran synchronously on Main UI thread, causing ANRs. Offloaded geocoding to withContext(Dispatchers.IO) with coroutine safety and timeout fallbacks. RESOLVED
5 Release Minification isMinifyEnabled = false in release build, exposing debug symbols and bloating APK. Enabled isMinifyEnabled = true and configured optimized ProGuard keep rules. RESOLVED
6 ProGuard Configuration proguard-rules.pro was empty, containing only commented template text. Authored comprehensive rules for Coroutines, ViewModels, Compose, and domain data models. RESOLVED
7 Debug Keystore Handling Debug keystore in workspace root; cloud build required resilient fallback. Implemented dynamic signing config fallback in Gradle to ensure flawless continuous builds. RESOLVED
8 Backup Data Leakage allowBackup="true" with blank XML rules, risking credential leakage to Drive. Hardened backup_rules.xml and data_extraction_rules.xml with strict exclusions. RESOLVED
9 Ghost Dependencies Unused Retrofit, Moshi, OkHttp, and Firebase AI dependencies declared in build. Pruned unintegrated libraries from build.gradle.kts and disabled KSP plugin. RESOLVED
10 Firebase App Check App Check dependencies declared without runtime initialization. Commented out unconfigured App Check libraries to remove unnecessary overhead. RESOLVED
